FitLog · 训练日志

一个纯前端的健身记录工具：训练、饮食、身体数据，全部存在你自己的浏览器里。

v1.0 · 本地存储

训练记录

按部位记录动作、组数、重量、时长与强度，自动算训练容量和估算消耗，支持模板一键填充。

饮食记录

内置 28 种常见食物，按份量自动算热量与三大营养素；没收录的食物可以手动填。

趋势统计

体重趋势、训练热力图、周容量、部位分布、个人最佳重量，全部由本地记录实时计算。

保存后全局生效

使用说明

怎么打开

双击 index.html，用 Chrome / Edge 打开即可。全部是静态文件，不需要安装环境，也不需要联网。

数据存在哪

浏览器 localStorage（键名 fitlog.v1）。不会上传任何数据；清理浏览器数据会一起清掉，所以建议定期导出备份。

记录建议

训练当天记「部位 + 动作 + 重量 × 组数 × 次数」，饮食按实际份量记，体重固定早上空腹称。坚持两周，趋势图就有意义了。

技术说明

原生 HTML / CSS / JavaScript，无框架无构建；图表是手写 SVG；深色 / 浅色主题用 CSS 变量切换；响应式适配手机。
